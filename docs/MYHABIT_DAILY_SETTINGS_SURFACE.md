# Myhabit daily workspace and settings surface

Mode: Operate.

Targets: `app/pages/today.vue`, `app/pages/settings.vue`, shared module preferences and day-plan forms.

Users should see what is due, complete the right item and understand which date or module a setting affects. Warm surfaces and a restrained terracotta accent retain Myhabit identity. Global theme stays consistent across modules. Desktop uses a settings side rail; mobile uses a category selector. Controls keep visible focus, labels and comfortable touch targets.

Global preferences are inherited unless a module or item explicitly overrides them. Schedule edits start tomorrow. Day overrides name the selected date, and skipping never counts as completion. Recorded plans keep their original metadata and habit threshold. Habit progress remains separate from optional check-ins.

See `PRODUCT.md` for product constraints and `DESIGN.md` for shared visual tokens.
