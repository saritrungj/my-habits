# Design Context

## Users

People managing daily routines, personal tasks and optional life check-ins. They use Thai and English interfaces on phones and desktops. The workspace brings habits and related daily modules together, with tools available when needed.

## Brand and Visual Direction

Preserve Myhabit identity and Anuphan. The user requested a full UX/UI redesign with a calm, comfortable visual character in both light and dark modes. The implemented direction uses warm cream, quiet sage and restrained terracotta, flat surfaces, clear rows and generous breathing room.

The theme is global: system, light or dark. Use the semantic variables in `app/assets/css/main.css` across modules. `DESIGN.md` records the current tokens and patterns; `.impeccable/design.json` provides matching component previews and extensions.

## Design Principles

- Daily settings and planning are understandable and reversible.
- Keep recorded habit progress and streaks distinct from tasks, goals, focus and mood.
- Optional check-ins reflect real records; tools do not become compulsory daily work.
- Make Thai and English readable with natural wrapping and stable numeric counters.
- Support phone and desktop use, visible keyboard focus, descriptive controls and reduced motion.
- Use color for actions and state, with borders and space establishing the hierarchy.

## Implemented Responsive Patterns

Desktop navigation uses a sidebar at 1024px and above; smaller screens use bottom navigation. Today uses an overview beside the agenda from 1200px. Tool discovery uses divided rows that stack on phones. Both themes share the same composition and interaction model.

Finance records stack below 640px with category/date copy above amount and actions, preserving readable metadata on phones.

## Shared Interaction System

The approved interaction extension uses `--motion-fast: 140ms`, `--motion-state: 220ms` and `--ease-out: cubic-bezier(.16,1,.3,1)` from the global stylesheet. Controls respond through color, border and opacity; fine-pointer hover adds restrained tonal feedback and a 2px trailing-link icon shift. Pressed controls move 1px and keyboard focus stays visible. Check and conversion confirmations take 220ms, progress updates 300ms, workspace entry/exit 160ms/100ms, and loading rotation 900ms only while loading. Reduced motion removes movement and loops, keeps workspace transitions still, and reduces durations to .01ms.

Success notifications sit at top center with one current message and Undo for reversible changes. New feedback replaces the prior message; switching owners clears it. Preserve this interaction model and the existing calm identity in both themes.

## Evidence Outside This Extension

The detector report `.impeccable/review/detect-completion.json` contains pre-existing type-ramp advisories, including `.8rem` in the shared stylesheet. They remain review evidence, not additions to the normative typography scale; this interaction extension does not repair or canonize them.
